Claude Code 플러그인 · 버전 0.3.0

한글에서 바로 열리는 HWPX 문서를 Claude가 만들고 읽고 고칩니다

공문, 보고서, 회의록, 신청서를 말로 시키면 HWPX 파일이 나옵니다. 문서를 만들고 읽는 데는 한글 프로그램 없이 Python 표준 라이브러리만 씁니다.

/plugin marketplace add BlackBuddle/hwpx-docs
/plugin install hwpx-docs@blackbuddle

Claude Code에서 두 줄을 입력하면 스킬 11개가 생깁니다.

할 수 있는 일

만들기

JSON 스펙, Markdown, HTML로 문서를 만듭니다. 셀 병합과 셀별 선·채움이 있는 표, 그림, 도형, 수식, 한글 차트, 머리말·꼬리말, 각주를 씁니다.

hd build · hd md · hd html

읽기

기존 HWPX를 스펙(JSON)이나 텍스트·Markdown으로 꺼냅니다. 표는 Markdown 표로, 각주는 [^n]으로 바꿉니다.

hd read · hd text

고치기

받은 양식에 칸 이름(성명, 연락처)이나 칸 번호로 값을 넣고 체크 상자를 표시합니다. 바꾼 뒤에는 구조와 줄 수, 남은 ○○ 같은 자리표시를 검사합니다.

hd slots · hd edit · hd guard

검사

단어 중간 줄바꿈이나 양쪽 정렬로 벌어진 빈칸처럼 읽기 어려운 곳을 찾습니다. 주민등록번호·전화번호 같은 개인 정보는 한글 없이 가립니다.

hd readability · hd secure --mask-private

한글 없는 미리보기

자체 렌더러가 표, 차트, 수식, 각주, 세로쓰기를 한글의 쪽 나눔 규칙대로 그리고 결과는 SVG·HTML로 어디서나 볼 수 있습니다. PNG는 Windows의 Edge로 만듭니다.

hd preview

가독성 프로필

제목만 쪽 끝에 남은 곳이나 한 줄만 넘어간 곳을 고칩니다. "읽기 좋게"라고 하면 readable 프로필이 표와 캡션 같은 읽기 단위를 한 쪽에 모으고 긴 표는 머리 행을 반복합니다.

hd pagefit check · hd pagefit fix

공문 규칙

공문 시작 스펙과 gongmun-style 스킬로 어투, 항목 기호, 날짜·금액 표기를 맞추고 기안문을 검사합니다.

hd gongmun-check

예제

한글 2024가 그린 1쪽입니다. 그림을 누르면 원본 스펙과 HWPX 파일이 있는 폴더로 갑니다. 기관, 사람, 연락처는 모두 가상입니다.

이렇게 씁니다

  1. 참고자료를 하나씩 건네고 계획서 초안을 부탁합니다. 이 자료를 바탕으로 다음 단계 계획서를 공문 형식으로 써 줘.
  2. 쓴 Markdown을 한글 문서로 바꿉니다. 이 계획서를 한글 문서로 만들어 줘. hd md plan.md plan.hwpx
  3. 쪽 넘김을 다듬습니다. 읽기 좋게 쪽을 맞춰 줘. hd pagefit fix plan.hwpx plan-fit.hwpx --profile readable
  4. 쪽마다 확인합니다. 한글이 없으면 hd preview로 쪽 그림을 봅니다.

전체 과정은 README의 사용 예에 있습니다.

요구 사항

작업필요한 것
만들기, 읽기, 고치기, 검사, 쪽 맞추기, 미리보기(SVG·HTML)Python 3.10 이상. 운영체제와 한글 설치는 상관없습니다
미리보기 PNG, 실제 글꼴 폭으로 줄 수 계산Windows, Microsoft Edge
한글로 쪽 그리기, HWP↔HWPX 변환, PDF 저장, 문서 암호Windows, 한글 2024, pywin32

한계

  • .hwp는 직접 읽거나 쓰지 않습니다. 한글로 HWPX로 바꾼 뒤 씁니다.
  • 자체 미리보기는 한글이 그린 쪽과 같은 이미지가 아닙니다. 글자 효과와 무늬 채움은 그리지 않습니다.
  • edit는 글자만 바꾸고 행이나 표를 늘리지 않습니다.
  • 개인 정보 가리기는 암호화가 아니며 정해진 형식만 찾습니다.
  • 남이 준 스펙으로 만들 때는 그림 경로(src)가 가리키는 파일을 먼저 확인하십시오.
  • 한글 기능 167항목 가운데 156항목을 지원합니다(대응 범위).

In English

hwpx-docs is a Claude Code plugin that makes, reads, edits and checks HWPX documents (OWPML, KS X 6101) for Hancom Office Hangul. Making and reading need only the Python 3.10+ standard library on any OS. An own renderer previews pages without Hangul, and page-fit profiles keep headings, tables and captions together. Rendering in Hangul, conversion and passwords need Windows with Hangul 2024. License: AGPL-3.0-or-later.
