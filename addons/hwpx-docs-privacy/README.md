# hwpx-docs-privacy

hwpx-docs의 선택 추가 플러그인입니다. 한글 문서(HWP, HWPX)를 클라우드 모델과 함께 다룰 때 평소 작업에서 개인정보가 모델로 나가지 않게 합니다(일부러 하는 우회는 막지 못합니다. 아래 한계 참조). 필요한 사람만 설치하면 되고, 설치하지 않으면 본체 hwpx-docs는 그대로 가볍습니다.

## 하는 일

- 모델은 `hd`가 보여 주는 글에서 가명만 봅니다(찾는 규칙에 기반하므로 낯선 배치는 놓칠 수 있습니다). 문서에서 읽는 주민번호, 전화번호, 주소, 계좌, 이름 같은 값은 `⟪주민번호1｜1980년대·남⟫`, `⟪성명1⟫`, `⟪전화번호1⟫` 같은 짧은 태그로 바뀌어 나옵니다. 진짜 값은 이 PC의 금고(Windows DPAPI)에만 있습니다.
- 주민번호는 나이대와 성별만 보여 줍니다. 정확한 값은 `pv.py calc`가 이 PC에서 계산합니다(나이, 성별, 같은 값인지, 개수).
- 모델이 태그로 편집하면 문서를 쓰기 직전에 태그가 진짜 값으로 돌아가고, 태그 뒤 조사도 진짜 낱말에 맞게 고쳐집니다. 모르는 태그는 오류입니다.
- 켜짐은 사용자별 설정 파일(`%LOCALAPPDATA%\hwpx-docs\addons.json`)에 있어서 훅이 못 붙은 경우나 직접 `python lib/hd.py` 호출에도 적용됩니다. 추가 플러그인을 못 불러오면 본체는 문서 글을 보여 주지 않고 멈춥니다.
- 훅이 원본 읽기(Read, Grep, Bash, PowerShell, Monitor)를 막고, 붙여 넣은 확실한 개인정보(검증 통과 주민번호, 카드, 이름표 붙은 계좌)는 모델로 보내기 전에 막습니다.
- `hd text -o`나 spec 같은 파생 파일은 가려서 쓰고, 그림은 가린 사본으로 그립니다. 문서 정보, 변경 추적, 메모, 숨은 설명, 그림 정보(EXIF), OLE 안, 미리보기까지 가린 사본은 `pv.py mask-copy`로 만듭니다.

## 쓰는 법

1. hwpx-docs 본체를 먼저 설치하고, 이 플러그인을 설치합니다: `/plugin install hwpx-docs-privacy@blackbuddle`(마켓플레이스 `BlackBuddle/hwpx-docs`는 본체와 같습니다).
2. 평소처럼 문서를 요청합니다. 스킬 `hwpx-privacy`가 태그로 읽고 쓰는 순서를 알려 줍니다.
3. 금고 명령은 `python scripts/pv.py <명령>`입니다: `list`(태그 목록, 값은 안 보임), `audit`(무엇을 가렸는지 기록), `forget <문서>`, `purge --yes`, `status`, `enable`/`disable`(터미널에서만).
4. 수준은 설정 파일의 `mode`로 고릅니다: `standard`(기본, 식별 번호·이름·연락처·금융·그림·문서 정보), `strict`(질환·죄명 같은 사전 낱말, 기타 번호, 생년월일·나이·학교·직장, 가족, 써 넣은 모든 칸도 가림). 환경변수 `HWPX_PRIVACY_MODE=strict`는 올리기만 합니다. 끄려면 `pv.py disable`을 터미널에서 씁니다(끄면 다음 세션 시작에도 켜지 않고, `pv.py enable`로 다시 켭니다).
5. 빈 양식 폴더를 `HWPX_PRIVACY_TEMPLATES`에 지정하면, 양식에 사람이 적어 넣은 개인 칸의 값은 모양과 관계없이 가립니다.

## 들어 있는 묶음(모두 데이터, 서로 독립)

| 묶음 | 종류 |
|---|---|
| `kr-identifiers` | A 주민번호, 외국인등록번호, 여권, 운전면허 |
| `kr-person` | B 이름, F 생년월일·나이·국적·학교·직장(strict), G 가족(strict) |
| `kr-contact` | C 주소, 우편번호, 전화, 이메일, SNS, IP, MAC, 좌표, 차량번호 |
| `kr-finance` | D 계좌, 카드와 비밀정보, 증권계좌, 지갑, 소득·부채, 신용, 사업자번호 |
| `kr-other-ids` | E 학번, 사번, 군번, 수험번호, 환자번호, 보험번호, 사건번호, 민원번호, 회원번호, 자격번호(strict) |
| `kr-sensitive-terms` | H·I 민감 낱말 사전(질환, 약, 죄명, 종교, 정당·노조, 장애 유형)(strict) |
| `doc-hidden` | J 숨은 곳(문서 정보, 변경 추적, 메모, 숨은 설명, 그림, OLE, 이름, 미리보기, 스크립트) |
| `kr-lookalike` | 제품번호·바코드처럼 주민번호와 닮은 번호 |
| `kr-fixed-text` | 공개 빈 양식의 고정 문구와 공개 번호(오탐 방지) |

새 나라나 새 종류는 새 묶음 폴더 하나로 더합니다. 형식과 한계는 본체 저장소의 `docs/privacy.md`에 있습니다.

## 한계

이 층은 보통 작업에서 생기는 실수(습관적으로 문서를 읽거나, 명령이 값을 찍거나, 파일을 무심코 여는 것)를 막는 장치입니다. 일부러 만든 명령이나 스크립트, 모델이나 사용자가 일부러 하는 우회는 막지 못합니다. 파일 이름은 가리지 않으므로 파일 이름에 사람 이름을 넣지 마십시오. 자세한 한계와 알려진 우회는 본체 저장소의 `docs/privacy.md` 8절에 있습니다.

> 한글, 한컴오피스는 (주)한글과컴퓨터의 상표 또는 등록 상표입니다. 이 프로젝트는 (주)한글과컴퓨터와 관계가 없습니다.
